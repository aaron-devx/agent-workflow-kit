# Optional: Caveman mode

**Not part of the core kit.** Optional shorter agent replies (same technical accuracy).

## Install

Symlink or copy a **caveman** skill into your host (e.g. `~/.cursor/skills/caveman`). This repo does not vendor caveman.

## Use

- Turn on: `/caveman` or say “caveman mode”.
- Turn off: “normal mode” or `stop caveman`.

## When to skip

Long-form docs, user-facing copy, or hosts that require full prose (check project `AGENTS.md` — project wins).
